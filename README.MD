# Taite Perumal — Developer Portfolio

A responsive developer portfolio built with vanilla HTML, CSS, and JavaScript, featuring live GitHub repository integration, an animated hero section, and a dark "developer" themed UI.

## Live site
https://0day-1s.github.io/portfolio/

## Built with
- HTML5, CSS3, JavaScript (no frameworks)
- GitHub REST API for live project data
